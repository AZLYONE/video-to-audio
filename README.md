# 视频转音频

Windows 桌面工具：从本地视频和无需登录的公开视频中提取音频，并传到手机。此公开仓库用于发布安装包和使用说明，不包含本应用的源代码。

## 下载与安装

前往 [GitHub Releases](https://github.com/AZLYONE/video-to-audio/releases) 下载最新 Windows 安装包。

- 支持 Windows 10/11，64 位。
- 下载 `.exe` 后运行安装程序，可选择安装位置。
- 安装包目前未进行代码签名，Windows 可能显示安全提示；请只从本仓库的 Releases 下载。

## 功能

- 导入本地视频，或添加抖音、B站无需登录的公开视频链接。
- 默认直接保留来源音轨，不重新编码；可另存 AAC/M4A 手机兼容副本。
- 显示音频编码、采样率、码率和有损/无损信息。
- 可修改文件名、曲名、歌手、专辑和封面。
- 支持批量处理、失败重试，以及将 B站合集或播放列表展开后选择条目。
- 默认保存到 Windows“音乐/视频转音频”文件夹。
- 电脑和手机连接同一 Wi-Fi 后，可用二维码打开临时传输页面：iPhone 保存到“文件”App，Android 保存到“下载”文件夹。传输在局域网内进行，不经过云端。

## 音质说明

软件保留来源音轨时不会重新编码。来源音轨如果本身是有损格式，保存或转换为 FLAC 也不会恢复丢失的音质。AAC/M4A 手机兼容副本会重新编码，可能有损；原始提取音轨会单独保留。

## 使用范围

仅处理无需登录、且你有权保存的公开视频。软件不会使用登录 Cookie，也不会绕过登录、付费或其他访问限制。网站规则可能变化，链接解析功能可能受平台调整影响。

## 检查更新

安装后可在应用的“设置 → 应用更新”中检查更新。应用会查询本仓库的公开 Releases；发现新版本后由你决定是否打开下载页，不会静默安装。

## 第三方组件

安装包包含 FFmpeg 和 ffprobe，并会在首次解析公开视频时从 yt-dlp 官方 GitHub Releases 下载 yt-dlp。第三方许可和构建信息随安装包提供；发布版本的说明中会列出相关第三方材料。
